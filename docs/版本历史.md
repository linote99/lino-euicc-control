## 恢复说明

v1.0 起的模块 zip 是从测试设备上残留的副本中回收的；v2.0 及以上的包因体积较大，
回收时只取回了本项目的文件（源码/配置/APK），第三方 `OpenEUICC.apk` 与
`liblpac-jni.so` 由已知副本补入 —— 重组后的包体积与原始文件**逐字节一致**
（已用 APK md5 校验）。

插件早期版本（v1.0/v1.1/v1.3）在开发中被新版覆盖后清理，无法恢复。
